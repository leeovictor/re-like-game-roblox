# Objective Notification Component Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the objective notification's hook usage, visual tree and animation from `App.luau` into a self-contained `ObjectiveNotification` component without changing its behavior.

**Architecture:** `ObjectiveNotification.luau` will be a prop-less React component that calls `useObjectiveNotification()` internally, renders the notification when a batch exists, and owns the ref, `TweenService` animation and cleanup. `App.luau` will only mount that component as the `Notice` child of the existing `ObjectiveStack`; the objective hook and shared timing module remain in `src/client/objectives`.

**Tech Stack:** Luau `--!strict`, Roblox `TweenService`, React 17.2.1, ReactRoblox 17.2.1, TestEZ in Roblox Studio, Rojo 7.7.0, Selene 0.29.0 and luau-lsp 1.69.0.

## Global Constraints

- Preserve the current one-second entry delay, 0.5-second fade in, five-second fully visible interval, 0.5-second fade out and removal.
- A new objective batch replaces the old notification and restarts the entry delay; batches are not queued.
- `useObjectiveNotification()` continues returning `{ ObjectiveView }?` and `ObjectiveController` remains unchanged.
- `ObjectiveNotification` consumes `useObjectiveNotification()` internally and receives no props.
- `App.luau` remains the owner of the high-level React tree but no longer owns notification-specific rendering or animation.
- Keep the objective notification inside `ObjectiveStack` with its current `LayoutOrder`, position and layout relationship to the permanent objective panel.
- Animate only the notification text, background and `UIStroke`; do not animate the permanent objective panel.
- Do not change pickup notification timing or behavior.
- Specs of UI remain outside the TestEZ scope; verify the animation manually in Roblox Studio.
- Keep `--!strict`; do not use `--!nocheck`, broad ignores or disabled type errors.
- Do not edit `Packages/` or `DevPackages/`; those directories are generated by Wally.
- Preserve script-based imports and the existing `default.project.json` and `test.project.json` mappings.
- Do not alter `ObjectiveController.luau`, `ObjectiveConfig.luau`, `useObjectives.luau`, `useObjectiveNotification.luau` or `ObjectiveNotificationTiming.luau` for this refactor.
- Inspect the current `App.luau` before editing and preserve the already implemented objective-system and notification-animation changes; move only the notification-specific code.
- Do not create commits. After each task's verification, stop and wait for the user's manual review before starting the next task.

### Task 1: Create the Self-Contained Objective Notification Component

**Files:**
- Create: `src/client/ui/ObjectiveNotification.luau`
- Read only: `src/client/ui/App.luau`, `src/client/objectives/useObjectiveNotification.luau`, `src/client/objectives/ObjectiveNotificationTiming.luau`

**Interfaces:**
- Consumes: `useObjectiveNotification(): { ObjectiveView }?`, the timing table fields `fadeInDuration`, `visibleDuration` and `fadeOutDuration`, React 17 hooks and Roblox `TweenService`.
- Produces: a prop-less React function component named `ObjectiveNotification` that returns `nil` without an active batch or a `TextLabel` tree with the existing notification appearance.

- [ ] **Step 1: Create the component module with the existing notification behavior**

Create `src/client/ui/ObjectiveNotification.luau` with `--!strict`, the sibling domain imports, and the following structure. Keep the local `nextFadeOut` variable so strict type checking can prove that the fade-out tween is non-nil before calling `Play()`:

```lua
--!strict

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local TweenService = game:GetService("TweenService")

local React = require(ReplicatedStorage.Packages.React)
local useObjectiveNotification = require(script.Parent.Parent.objectives.useObjectiveNotification)
local timing = require(script.Parent.Parent.objectives.ObjectiveNotificationTiming)

local function ObjectiveNotification()
	local objectiveNotification = useObjectiveNotification()
	local objectiveNotificationRef = React.useRef(nil :: TextLabel?)

	React.useEffect(function()
		local notification = objectiveNotificationRef.current
		if objectiveNotification == nil or notification == nil then
			return
		end

		local active = true
		local strokeInstance = notification:FindFirstChild("Stroke")
		local stroke = if strokeInstance ~= nil and strokeInstance:IsA("UIStroke") then strokeInstance else nil
		local fadeOut: Tween? = nil
		local strokeFadeOut: Tween? = nil

		local fadeIn = TweenService:Create(notification, TweenInfo.new(timing.fadeInDuration), {
			TextTransparency = 0,
			BackgroundTransparency = 0.08,
		})
		local strokeFadeIn = if stroke ~= nil
			then TweenService:Create(stroke, TweenInfo.new(timing.fadeInDuration), { Transparency = 0.25 })
			else nil

		fadeIn:Play()
		if strokeFadeIn ~= nil then
			strokeFadeIn:Play()
		end

		task.delay(timing.fadeInDuration + timing.visibleDuration, function()
			if not active then
				return
			end
			local nextFadeOut = TweenService:Create(notification, TweenInfo.new(timing.fadeOutDuration), {
				TextTransparency = 1,
				BackgroundTransparency = 1,
			})
			fadeOut = nextFadeOut
			strokeFadeOut = if stroke ~= nil
				then TweenService:Create(stroke, TweenInfo.new(timing.fadeOutDuration), { Transparency = 1 })
				else nil
			nextFadeOut:Play()
			if strokeFadeOut ~= nil then
				strokeFadeOut:Play()
			end
		end)

		return function()
			active = false
			fadeIn:Cancel()
			if strokeFadeIn ~= nil then
				strokeFadeIn:Cancel()
			end
			if fadeOut ~= nil then
				fadeOut:Cancel()
			end
			if strokeFadeOut ~= nil then
				strokeFadeOut:Cancel()
			end
		end
	end, { objectiveNotification })

	if objectiveNotification == nil then
		return nil
	end

	return React.createElement("TextLabel", {
		BackgroundColor3 = Color3.fromRGB(20, 22, 30),
		BackgroundTransparency = 1,
		LayoutOrder = 1,
		Size = UDim2.new(1, 0, 0, 0),
		AutomaticSize = Enum.AutomaticSize.Y,
		Font = Enum.Font.GothamBold,
		ref = objectiveNotificationRef,
		Text = (if #objectiveNotification == 1 then "NOVO OBJETIVO" else "NOVOS OBJETIVOS")
			.. "\n"
			.. table.concat((function()
				local texts = {}
				for _, objective in objectiveNotification do
					table.insert(texts, objective.text)
				end
				return texts
			end)(), "\n"),
		TextColor3 = Color3.fromRGB(241, 237, 255),
		TextSize = 14,
		TextTransparency = 1,
		TextWrapped = true,
		TextXAlignment = Enum.TextXAlignment.Left,
		TextYAlignment = Enum.TextYAlignment.Center,
	}, {
		Padding = React.createElement("UIPadding", {
			PaddingBottom = UDim.new(0, 12),
			PaddingLeft = UDim.new(0, 14),
			PaddingRight = UDim.new(0, 14),
			PaddingTop = UDim.new(0, 12),
		}),
		Corner = React.createElement("UICorner", {
			CornerRadius = UDim.new(0, 8),
		}),
		Stroke = React.createElement("UIStroke", {
			Color = Color3.fromRGB(107, 92, 168),
			Transparency = 1,
		}),
	})
end

return ObjectiveNotification
```

Call the hook, ref and effect unconditionally before the `nil` return so the component keeps a stable hook order while it is mounted without visual children.
